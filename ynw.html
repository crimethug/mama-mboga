How to Create the Folder Structure in VS Code

1. Create the main project folder

  1. Open VS Code.
  2. Select File → Open Folder....
  3. Create a folder named mama_mboga and open it.

2. Create the folders

In the Explorer panel, create these folders:

  1. Create templates inside mama_mboga.
  2. Create static inside mama_mboga.
  3. Create css inside static.
  4. Create js inside static.

3. Create the files

Location File name
Project root (mama_mboga)app.py
Project rootrequirements.txt
Inside templatesindex.html
Inside static/cssstyle.css
Inside static/jsapp.js

Project structure

mama_mboga/
├── app.py
├── requirements.txt
├── templates/
│   └── index.html
└── static/
    ├── css/
    │   └── style.css
    └── js/
        └── app.js

4. Run the app

  1. The project files are now in their matching folders shown above.
  2. Open the VS Code terminal with Ctrl + `, or select Terminal → New Terminal.
  3. Install the dependencies and start the application:
pip install -r requirements.txt
python app.py

Keep the terminal open, then visit http://127.0.0.1:5000 in your browser. Create an account on your first visit, then log in.
